# Super Kart Racer (demo)
## requirements: 
* pygame >=1.9.6 (pygame.org)
* pytmx >=3.21.7 (https://pypi.org/project/PyTMX/)
* numpy >= 2.0.0
* numba 
* tomlkit

## how to play:
* Execute "run.py" to start the game
* Choose a kart and track, confirm with ENTER
* Control the kart with WASD
